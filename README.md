## 💻 **Projetos**

### 🦠 Dengue Data Engine 

> Pipeline completa de armazenamento e distribuição de registros de casos de Dengue.

- Pipeline de ingestão, armazenamento e distribuição para milhões de registros epidemiológicos de dengue (SINAN/DATASUS);
- Núcleo de armazenamento em C++ com heap files e indexação via mergesort, permitindo busca binária eficiente;
- Integração C++/Python via pybind11 (build com CMake), eliminando I/O e serialização intermediária;
- API REST (FastAPI) com filtro por cidade e intervalo de data, mais granular que a API oficial (só por ano);
- Modelo preditivo Holt-Winters para projeção de casos de dengue por município, exposto via API.

➡️ [Ver projeto](https://github.com/Victor-SRambo/dengue-data-engine)

### 🤝 Maratona de Programação SBSC 2026

> Sistema de auditoria de despesas públicas do Portal da Transparência.
    
- Backend em Python para coleta e armazenamento de duas décadas de despesas públicas do Portal da Transparência;
- API REST modular (FastAPI) com busca de despesas por CNPJ de fornecedor;
- Schema de banco otimizado com tipos compactos e índices compostos por data e município;
- Pipeline de importação de CSVs direto para MySQL, dobrando a performance de carga do banco;
- Sistema modular de normalização SQL (pagamentos, liquidações, empenhos), reduzindo implementação de novas regras para minutos.


➡️ [Ver projeto](https://github.com/Maratona-de-Programacao-SBSC/maratonaSBSC)
